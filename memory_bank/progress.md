- **2026-10-16 (Chemistry Lab stoichiometry/nomenclature generator)** — Added the **Stoichiometry & Nomenclature** practice workbench (`chemlab/StoichiometryPractice.jsx`, pure logic in `chemlab/stoichiometry.js`), the next Priority-1 event-specialized tool. It generates five problem types — balance equations, mole/mass/particle gas-volume conversions, limiting reagent, percent yield, and ionic name ↔ formula — with **Check** grading and a step-by-step worked solution, plus a session-only practice score. Equation balancing uses an **exact rational null-space solver** (`balanceEquation`) over a curated reaction-species library (a unit test proves every entry balances with positive integers and conserves mass), so coefficients are computed rather than stored. Formulas are parsed to element counts (subscripts + nested parentheses), molar masses come from standard atomic weights, and names use crossed charges with Stock Roman numerals for variable-charge transition metals. The manual's §3.d ion lists are encoded exactly (Regional: main-group monatomic ions + acetate, ammonium, bicarbonate, carbonate, cyanide, hydroxide, nitrate, phosphate, sulfate; State/National adds chromate, dichromate, permanganate, peroxide, thiocyanate, transition-metal ions, and -ite/-ate with hypo-/per- prefixes), with a Regional/State toggle. No persistence (matches the sibling LogicDrill and the spec default). Added `tests/chemlab-stoichiometry.test.js` (11 cases: parser, molar mass, ion combining incl. parentheses/Roman numerals, solver, all-library mass balance, seeded generator self-consistency, Regional ion filtering, conversion consistency), registered the module lazily as `stoichiometry` (`ti-atom`), extended `tests/e2e/app-map.json` and the chemlab e2e spec. 113 unit + 96 e2e tests; lint/build clean (StoichiometryPractice chunk 25.0 kB / gzip 7.9 kB).
