# Anatomy and Physiology C — 2027 tool planning

The previous tool specifications were based on an older event focus and are retired. The official 2027 event page identifies the Respiratory, Digestive, and Immune systems.

No quiz bank, system checklist, formula, or scoring behavior is approved until the 2027 Rules Manual and current corrections/clarifications are reviewed. After review, derive tools only from the exact 2027 scope and cite the source rule for each feature.
