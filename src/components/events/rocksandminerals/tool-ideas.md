# Rocks and Minerals C — verified 2027 tool plan

Source: supplied 2027 Division C Rules Manual, pp. C52–C56, including the official mineral/rock list. Do not use previous-year lists, scoring assumptions, or taste/HCl testing. Identification may use provided diagnostic properties; HCl is neither used nor supplied.

## Official-list specimen and property practice
Load only the 2027 National list, tagging starred specimens as State/National. Practice identification using permitted observable/diagnostic characteristics and explanatory questions. Implement official footnotes (e.g. feldspar accepted names, Tourmaline generic identification, Bauxite classification, Rock Salt/Halite equivalence).

## Process and diagram practice
Cover only listed physical properties, habits, compositions/solid solutions, two-component phase diagrams, crystal systems, mineral formation/uses, Bowen’s series, and igneous/sedimentary/metamorphic content. Gate incompatible elements and thin-section microscopy to State/National. Keep identification share 30–50% and balance rock/mineral topics in authored practice sets; that percentage is for competition emphasis, not an invented score prediction.
