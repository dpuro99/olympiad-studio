# Rocks and Minerals C — 2027 tool planning

Previous tool specifications are retired pending a rule-packet review. The official 2027 event page establishes a high-level objective of identifying and classifying rocks and minerals and connecting them to geologic processes, Earth history, resources, and society.

Do not load prior-year specimen lists, percentages, allowed-resource rules, or scoring tolerances as 2027 facts. Build new tools only from verified 2027 rules and lists, with source references for each dataset and behavior.
