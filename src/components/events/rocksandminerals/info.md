# Rocks and Minerals C — 2027 status

## Verified event-page scope
The official 2027 Science Olympiad event page describes identifying and classifying rocks and minerals and demonstrating how they help explain geologic processes, Earth history, natural resources, and human use.

## Verification boundary
The prior detailed draft contains list contents, identification percentages, allowed-resource rules, topic boundaries, scoring, and station assumptions that have not been verified against the 2027 Rules Manual. Those details are retired pending review of the current packet and corrections/clarifications.
