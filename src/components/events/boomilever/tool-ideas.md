# Boomilever C — 2027 tool planning

The previous tool specifications are retired because their compliance checks and scoring assumptions were not verified against the 2027 Rules Manual. The official event page establishes only the high-level task: build a cantilevered structure extending from a testing wall to support a load, with a score combining structural efficiency and a Load Scored Bonus.

Do not implement dimensions, materials checks, bonus conditions, or formulas until each requirement has been verified against the 2027 manual and current corrections/clarifications. Candidate tool concepts may be reconsidered after that rule mapping.
