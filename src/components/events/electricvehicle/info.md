# Electric Vehicle C — 2027 Rules Summary

**Status:** Verified against the supplied Division C Rules Manual, pp. C26–C31 (PDF pp. 31–36), and the current official EV clarification, checked October 8, 2026.

## Task and format
Teams design/build one electric vehicle. It travels in a set time, pushes a water bottle past a line, then reverses to stop near a target. Team up to 2; approximately 12 minutes; one vehicle must be impounded before the first time slot. Each team gets up to 8 minutes of event time and at most two runs.

## Key construction rules
- All electrical energy: at most eight AA batteries, 1.2–1.5 V each, no lithium/lead batteries; no energy storage beyond battery instantaneous output. Lasers prohibited.
- Max vehicle length 80.0 cm and width 35.0 cm. Rigid, fixed, foremost bottle pusher; rear-most accessible measurement point. No remote control/tether; vehicle moves as one unit.
- A kit/open-source kit requires at least two functional documented modifications; team must build its own bottle pusher. Code must be developed/contributed to by a current team member; single-source programs are prohibited.
- Target distance, target time and bottle-line distance are announced after impound. Bottle position varies by level: 2 m Regional/Invitational, 3 m State, 4 m National.

## Run workflow and scoring
Use the unsharpened #2 pencil to trigger the vehicle. Programming tools cannot be accessed after a run starts until vehicle retrieval. A run must move to count. See the manual for inspection timing, floor-testing limits, bottle-handling rules and definitions of failed runs.

Low score wins; final = better run score + final penalties. Run score = 100 + distance + time + bonuses + run penalties:
- Distance = 2.0 × vehicle distance (cm) + 1.0 × bottle distance (cm); failed run distance = 2500. If bottle is not beyond target or moving-bottle rules are violated, bottle distance = 400 cm.
- Time = 0.5 × |target time − run time|; failed run time is 0.00 s.
- Bottle bonus = −20 if bottle is fully beyond the bottle line.
- Pusher bonus = (measured foremost opening width − 35.0 cm) × 1.5 pt/cm.
- National-only event-time bonus = (event time used − 480)/30, applied to final score.
- Penalties: +150 per run with any competition violation; +300 per run with any construction violation; +50 non-modification penalty. Vehicle not impounded: +5000 final penalty.

## Current official clarification
The official EV FAQ confirms that program work by a competitor at the same school who is not on the 15-member team is allowed if current team members modified/contributed and the remainder was completed by a current competitor at the school or from the previous-year team. Check the linked clarification for precise interpretation.
