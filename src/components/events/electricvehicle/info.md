# Electric Vehicle C — 2027 status

## Verified event-page scope
The official 2027 Science Olympiad event page describes a vehicle using electrical energy as its sole propulsion: it travels in a set amount of time, pushes a bottle past a line, then moves backward to stop close to a Target Point.

## Verification boundary
The previous detailed summary describes an older task and scoring model and is retired. No dimensions, batteries, track geometry, run limits, scoring formulas, bonuses, penalties, or inspection requirements are asserted here. Those details must be checked against the complete 2027 Rules Manual and current corrections/clarifications before implementation.
