# Electric Vehicle C — 2027 tool planning

Previous tool specifications are retired because they assume an older task and scoring model. The official 2027 event page describes an electrically propelled vehicle traveling in a set amount of time, pushing a bottle past a line, then reversing to stop near a target.

No course geometry, allowed construction, dimensions, run timing, scoring formula, bonuses, or penalties are approved from that overview. Keep scoring disabled and derive each rule-specific tool only after checking the complete 2027 Rules Manual and current corrections/clarifications.
