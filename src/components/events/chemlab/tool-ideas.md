# Chemistry Lab C — 2027 tool planning

The previous tool specifications are retired; they were centered on older stoichiometry and reaction topics. The official 2027 event page identifies kinetics and gases as the focus.

No topic checklist, lab-equipment rules, safety logic, or calculation is approved from that high-level description alone. Once the current manual and corrections/clarifications are reviewed, candidate practice tools can be mapped to verified kinetics/gas rules and documented with rule citations.
