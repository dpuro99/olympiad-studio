# Circuit Lab C — verified 2027 tool plan

Source: supplied 2027 Division C Rules Manual, pp. C16–C17. Separate written-test scope from hands-on practice. Do not teach or score explicitly excluded material as event content.

## DC circuit and logic workbench
Practice Ohm’s law, series/parallel and open/short circuits, schematics, Kirchhoff voltage/current laws, PN junctions/diodes/LEDs, Boolean expressions, truth tables, De Morgan’s law and combinational logic. Add State/National-only clock/timing/flip-flop, transistor bias/logic and ideal op-amp sections. Exclude capacitance, AC theory, inductance, Thevenin/Norton and oscilloscopes.

## Safe hands-on task simulator
Train breadboard/multimeter basics and practice rule-listed task types: voltage-only mystery resistor, power, equally bright LEDs, charger-label analysis, truth-table circuit, troubleshooting, SPDT 3-way switch and equivalent resistance. Use low-voltage supplied components only; never simulate prohibited hazardous exposure as an event procedure.

Paper reference binders of any size and up to two Class III calculators are allowed. Written work is 50–75%; hands-on is 25–50%.
